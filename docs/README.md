## ✅ Requirements

- **git** to clone sources.
- **cmake 3.28** or later to build from sources.
- Any **C compiler** that supports **C11** (majors ones minimum versions):
    - gcc 4.9 or later.
    - clang 3.0 or later.
    - Xcode 4.2 or later.
    - Visual Studio 2019 16.8 or later.


## 🛠️ Building

- Cloning this repository:

```bash
git clone git@github.com:VMNL/vmnl-network.git
cd vmnl-network
```

- Building from the repository's root:

```bash
cmake -B build ; cmake --build build
```

## 🎮 Usage

In order to use this library as a standalone one (without VMNL), you must move it to your shared libraries folder (including `include` folder) and make sure it can be used from anywhere in your system.
Just link your project with `vmnl-network`, use the library's headers and voilà.
