# Watch

The research log of the library, newest first: for each source read or test run, its subject, what it changes or could change for the library, and what I did about it.
The first column gives what became of each entry: **Adopted** in a linked commit, **Planned** but not coded yet, **Candidate**, **Open**, **Deferred**, **Tested**, **Rejected**, or **No action**.
The papers and articles the library is built on are listed in [references](references.md).
